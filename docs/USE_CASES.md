# 业务用例

## 用例 1：报价转订单

1. 销售创建报价单。
2. 系统计算明细金额和总金额。
3. 报价发送客户。
4. 客户确认后转销售订单。
5. 报价状态变为已转订单。

## 用例 2：订单审核后库存校验

1. 销售提交订单。
2. 管理员或有权限人员审核订单。
3. 系统查询成品可用库存。
4. 库存足够：进入待发货。
5. 库存不足：创建生产计划，并根据 BOM 分析缺料。
6. 原料不足：进入采购提醒。

## 用例 3：分批发货

1. 仓库从订单生成送货单。
2. 填写本次发货数量。
3. 确认发货。
4. 系统扣减成品库存，写入流水。
5. 回写订单已发货数量。
6. 未发完状态为部分发货，发完状态为已完成。

## 用例 4：月底对账

1. 财务生成指定月份账单。
2. 系统按客户汇总已发货明细。
3. 财务核对账单并打印。
4. 登记发票。
5. 登记收款。
6. 系统更新应收、已开票、已回款和欠款余额。
